About

WarriorOG Glassmorphism is a portfolio experience focused on visual depth and interaction.

The design combines translucent glass surfaces, cinematic video, layered backgrounds, animated typography, responsive layouts, and interactive project sections into one cohesive interface.

It is built to feel fast, clean, and immersive without relying on a traditional portfolio layout.

Design

The visual system is built around four main ideas.

Glass

Transparent surfaces, blur, borders, reflections, and subtle gradients create the glass interface.

Depth

Multiple layers, scale, blur, and movement give the page a sense of depth instead of a flat layout.

Motion

Animations are used throughout the experience for navigation, typography, cards, transitions, and section entrances.

Contrast

Dark backgrounds and bright interface elements keep the content clear while maintaining the cinematic look.



Motion

Animations include:

- Animated hero content
- Blur-based text reveals
- Hover interactions
- Card transitions
- Section entrances
- Video background movement
- Modal transitions
- Layered visual effects
- Responsive motion

The animations are designed to support the interface rather than distract from the content.

Components

The interface is split into focused components for each major part of the experience.

Main sections

Hero · About · Capabilities · Selected Works · Tech Stack · Journal · Explorations · Statistics · Contact

UI components

Navigation · Loading Screen · Project Modal · Contact Modal · Journal Modal · Capability Modal · Blur Text · Video Backgrounds

This keeps the visual sections independent and makes the interface easier to extend.

Getting Started

Clone the repository and install the dependencies.

git clone https://github.com/WarriorOGZz/WarriorOG-Glassmorphism-Landing-Page.git

cd WarriorOG-Glassmorphism-Landing-Page

npm install

Start the development server:

npm run dev



Build

Create a production build:

npm run build

Preview the production build:

npm run preview

Run the project checks:

npm run lint



Browser Experience

The page is designed for modern browsers with support for:

- CSS backdrop filters
- Modern CSS transforms
- Video playback
- Responsive layouts
- Hardware-accelerated animation

For the best experience, use an up-to-date version of Chrome, Edge, Firefox, or Safari.
